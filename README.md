# AI-text-detector

## Overview

The **AI-Generated Text Detection System** is a machine learning-based project designed to identify whether a given text is written by a human or generated by an AI model.

The project explores different machine learning approaches, compares their performance, and evaluates their reliability through classification metrics and robustness experiments.

## Features

- **Text Detection:** Predicts whether input text is Human-Written or AI-Generated.
- **Model Comparison:** Compares the performance of multiple machine learning models.
- **Performance Evaluation:** Evaluates models using classification metrics.
- **Robustness Testing:** Conducts experiments to examine model performance under different text conditions.
- **Interactive Menu:** Provides a command-line interface to access different project functionalities.
- **Prediction Support:** Allows users to enter custom text for detection.

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Navigate to the Project Directory

```bash
cd AI-Generated-Text-Detector
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the environment:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## How to Run

Start the interactive menu:

```bash
python main.py
```

The system provides the following options:

1. Detect a text
2. Compare models
3. Run robustness experiment
4. Show evaluation metrics
5. Exit

### Running Individual Commands

The project also supports individual commands:

| Command | Description |
|---|---|
| `python main.py demo-data` | Generate demonstration dataset |
| `python main.py prepare` | Prepare the dataset |
| `python main.py train` | Train baseline and proposed models |
| `python main.py evaluate` | Evaluate models and run experiments |
| `python main.py predict "Your text"` | Detect whether the given text is AI-generated or human-written |

## Model Evaluation

The project includes model comparison and evaluation functionality to analyze the performance of the implemented machine learning approaches.

Robustness experiments are also conducted to examine the reliability of the detection system.

## Project Objective

The primary objective is to explore the application of machine learning in distinguishing human-written text from AI-generated content and to understand the challenges involved in building reliable text detection systems.
